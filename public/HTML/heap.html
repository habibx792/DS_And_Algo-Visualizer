Understanding Heaps

A Heap is a specialized tree-based data structure that satisfies the heap property. It's a complete binary tree where each node's value is either ≥ (max-heap) or ≤ (min-heap) its children's values.

Min Heap

  • Parent ≤ Children
  • Root is minimum element
  • Used in Priority Queues
  • Extract minimum in O(log n)

Max Heap

  • Parent ≥ Children
  • Root is maximum element
  • Used in Heap Sort
  • Extract maximum in O(log n)

📝 Heap Properties

  • Complete Binary Tree: All levels are filled except possibly the last
  • Heap Property: Parent dominates children (min or max)
  • Array Representation: For node at index i:
    • Parent: floor((i-1)/2)
    • Left Child: 2i + 1
    • Right Child: 2i + 2
  • Time Complexity:
    • Insert: O(log n)
    • Extract: O(log n)
    • Peek: O(1)
    • Build Heap: O(n)
  • Applications: Priority Queues, Heap Sort, Dijkstra's Algorithm, Median Maintenance

🔧 Heap Operations

Insertion

  1. Add element at the end
  2. Compare with parent
  3. Swap if heap property violated
  4. Repeat until property satisfied

Extraction

  1. Remove root element
  2. Move last element to root
  3. Heapify down from root
  4. Swap with smallest/largest child
