📚 Understanding Linked List

Node Structure

Each node contains data and a pointer to the next node. Doubly linked lists have additional prev pointer.

  • • Singly: Data + Next pointer
  • • Doubly: Data + Next + Prev pointers
  • • Circular: Last node points to first

Time Complexities

  • Access O(n)
  • Search O(n)
  • Insert Head/Tail O(1)
  • Delete Head/Tail O(1)

Linked List Properties

  • Dynamic size
  • Non-contiguous memory
  • Easy insertions/deletions
