📚 Understanding Queue

Enqueue Operation

Adds an element to the rear (end) of the queue. Time complexity: O(1)

  • • Element joins at the back
  • • Rear pointer moves forward
  • • Size increases by 1

Dequeue Operation

Removes an element from the front of the queue. Time complexity: O(1)

  • • Element removed from front
  • • Front pointer moves forward
  • • Size decreases by 1

Queue Properties

  • FIFO (First In First Out)
  • Constant time operations
  • Linear data structure

🌍 Real-world Applications

Printer Queue

Documents are printed in the order they were sent

CPU Scheduling

BFS Algorithm
