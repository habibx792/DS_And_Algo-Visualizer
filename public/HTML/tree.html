Understanding Trees

A Tree is a hierarchical data structure consisting of nodes connected by edges. Each tree has a root node and each node can have zero or more child nodes.

Preorder

Root → Left → Right

Inorder

Left → Root → Right

Postorder

Left → Right → Root

Level Order

Level by Level (BFS)

📝 Tree Properties

  • Binary Tree: Each node has at most 2 children
  • Binary Search Tree (BST): Left child < Root < Right child
  • Height: Length of longest path from root to leaf
  • Balanced Tree: Height difference ≤ 1 for all nodes
  • Used in: File systems, Databases, Network routing
